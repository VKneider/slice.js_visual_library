FileUpload

Overview

A drop zone for files that works with a mouse, a finger and a keyboard. The zone is a <label> wrapping a real <input type="file">, so the browser gives you click-to-open, focus and Enter/Space for free — none of which a clickable <div> would have.

API

  • accept (string) — extensions or MIME types, e.g. 'image/*,.png'. Empty means anything.
  • multiple (boolean) — allow more than one file.
  • disabled (boolean)
  • prompt (string, default 'Drag files here, or click to choose')
  • hint (string) — small print under the prompt, e.g. the size limit.
  • icon (string, default 'upload') — an Icon name; empty renders no glyph.
  • list (boolean) — show the picked files under the zone.
  • onFiles (function) — called as onFiles(filesArray, fileList)

The input is cleared after every pick, so choosing the same file twice still fires onFiles instead of silently doing nothing.

Prop Scenarios

Best Practices

Validate the files in onFiles rather than relying on accept: it is only a picker hint, and a user can still drop anything. Check type and size there, and tell them what you rejected.

Pitfalls

accept filters the picker, not the drop handler. A file dragged onto the zone is not filtered by it — always re-check files yourself.
