Icon

Overview

Icon renders an inline SVG glyph: no icon font, no webfont download, no global stylesheet. Use the name prop with the exact names listed below.

Icon used to render a glyph from the slc icon font, where every symbol came in a filled and an outlined variant. It now renders Lucide, which is stroke-only. - All 291 names still work. Names Lucide spells differently (trash-bin, angle-down, check-circle, ...) are aliased to their Lucide equivalent; the brand, language and Slice marks Lucide does not ship keep their original artwork. Run node scripts/icon-map-audit.mjs to see the full mapping, or read ALIASES in icons.generated.js. - iconStyle is a deprecated no-op. It is still accepted (and warns once) so existing callers keep working, but it no longer selects anything: drop it. - **The slc-* glyph classes are gone. If your CSS targeted slice-icon .slc-filrocket, delete that rule and style the host or the <svg> instead. The old stylesheet styled [class^="slc-"] at global scope, so those rules were leaking anyway. - color now defaults to currentColor, so an icon inherits its surroundings and follows the theme. Pass an explicit color to override. - Size and color land on the host, so getComputedStyle(icon).fontSize is meaningful and the glyph scales with the surrounding text. - A few names now draw the same glyph** (angle-down and caret-down are both the chevron) because Lucide merged the old duplicates.

API

  • name (string, default "youtube") — Icon symbol name (see full list below). An unknown name warns and renders nothing.
  • size (string, default "small") — "small" (16px), "medium" (20px), "large" (24px), or any CSS size.
  • color (string, default "currentColor") — Any CSS color value.
  • label (string, default "") — Accessible name. Omitted, the icon is aria-hidden (right next to a visible label); set it for an icon that stands alone.
  • iconStyle (string, "filled" / "outlined") — deprecated, ignored. Kept so existing callers do not break.

Setting any prop re-renders immediately; you no longer need a separate update() call.
