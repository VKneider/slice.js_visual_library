FileDownloadService

Overview

FileDownloadService is a Service component: a plain logic class (no DOM, no template) that saves content to the user's device as a file.

It exists because the "save a file from JS" snippet is short, easy to get subtly wrong, and gets copy-pasted into every app. Build it once with a sliceId and call it:

API

  • download(filename, content, mimeType = 'text/plain') — saves content as filename.
  • open(content, mimeType = 'text/plain') — opens the content in a new tab instead of saving it.

content may be a string or a ready-made Blob. When it is a Blob, the mimeType argument is ignored — a Blob already carries its own type.

Usage

Best Practices

Pass the mimeType even when the browser would guess from the extension. It decides whether the saved file opens in a text editor, a spreadsheet or an image viewer, and a wrong type is confusing in a way a wrong name is not.

Pitfalls

Never revoke the object URL yourself after calling download. The service already revokes it after a short delay, and revoking it immediately cancels the download in some browsers — the navigation has not started yet.
For a file larger than a few tens of MB, Blob + URL.createObjectURL is the only thing that works: a base64 data: URL has to fit in a string, and browser string limits are far below what that sounds like. Past that size, stream it from a server instead.
