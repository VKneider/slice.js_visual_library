NotFound

Overview

NotFound renders a 404 fallback page when no route matches the current URL. It sets the document title to its translated title on initialization.

API and Behavior

  • No props required. Displays a static 404 message.
  • Routes: use it as the final route or as MultiRoute's fallback.

Texts and translation

The three texts are marked and ship their own defaults (English and Spanish), so the component works with the translator off and translates itself when it is on:

An app dictionary that defines these keys wins; the defaults are registered in the translator's defaults layer, never overriding the app. The home button receives the key as a prop (slice.translator.ref), so it follows a locale change.

  • Automatically updates the page title on init().
  • Composable inside MultiRoute as the default fallback view.

Best Practices

Use NotFound as the final route inside MultiRoute to catch unmatched paths.

Pitfalls

NotFound is a presentation-only component. It does not provide automatic redirect logic.
