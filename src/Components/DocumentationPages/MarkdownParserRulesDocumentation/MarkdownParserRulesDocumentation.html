SEO Artifacts

docs:generate also writes two files from the same front matter, so they can never drift:

  • src/public/sitemap.xml — one <url> per real page (the generated docRoutes plus /,

/docs and /theme-creator), never a section index that has no page. <lastmod> is the markdown file's last commit date (not its mtime), so a fresh clone does not rewrite it.

  • src/public/seo.json — per-route title, description, robots, sitemap and jsonLd.

Internal routes (/__test, /playground, /game, /404) carry robots: false so they get served without being indexed, and the same file is what the framework's seo option reads.

Both are generated: edit parser/lib/seo.js or the front matter, never the XML/JSON by hand. parser/tests/seo.test.js fails when the committed sitemap does not match the generated routes.
